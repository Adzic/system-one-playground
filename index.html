Act automatically when the top probability ≥ τ, otherwise escalate to a human. This is the whole game: don't hide uncertainty inside the model — expose it.

How this works (honest version)

What's real: a quantized NLI model (Xenova/nli-deberta-v3-xsmall) runs 100% in your browser via Transformers.js. Each primitive maps to entailment: Noul = P(statement is true | state); Choice = entailment per option, normalized; Score = distribution over scale labels with the expected value reported. All questions run in parallel — the "single forward pass" spirit.

What's not real Jev: Jev trains with RLCD so its probabilities are calibrated; these are raw model scores — demo-grade, not decision-grade. Jev answers everything in one true forward pass; here we batch parallel calls.

The takeaway is the mechanism: decision = model.decide(state) with uncertainty exposed, and a threshold deciding autonomy. That's the idea worth stealing.
